## 2024-05-23 - [Date Formatting Optimization]
**Learning:** Instantiating new `Intl.DateTimeFormat` objects for formatting dates inside `toLocaleDateString` is very slow in Node.js/V8, especially when done in loops (e.g., when formatting many passages in a schedule). Caching these formatters using a `Map` provides a ~70x speedup (from 2281ms down to 33ms per 10k iterations).
**Action:** Use a global cache map for `Intl.DateTimeFormat` instances based on locale and options stringification to significantly reduce formatting overhead in repetitive calls (like `useTranslatedData` or API responses). Always check for valid dates when converting from string to avoid `Intl.DateTimeFormat.prototype.format` throwing a `RangeError`.
